# События

Для коммуникации с внешним окружением предлагается использовать механизм **событий** (events). Каждое отправленное событие обрабатывается основным (лобби)
сервером и (когда применимо) клиентом игры.

Есть ограничение: не более 20 событий в секунду. Если их становится больше — они встают в очередь. Если в очереди более 30 событий — они начинают отклоняться.

События сериализуются в JSON-объекты. Их структура произвольна и зависит от конкретного типа, хотя есть некоторые общие для всех поля:

| Название         | Тип     | Назначение                                                                        |
|------------------|---------|-----------------------------------------------------------------------------------|
| **target_index** | integer | Если указано: доставить событие только для игрока (ClientInfo) с заданным _index_ |
| **target_team**  | integer | Если указано: доставить событие только для игроков (ClientInfo) с заданным _team_ |
| **delay**        | float   | Если указано: выполнить действие отложенно (спустя указанное количество секунд)   |

## “updateUIItem”

Обрабатывается на клиенте. Создает элемент интерфейса (UI) с указанным ID: кнопку, окно, текст и подобные. Если элемент с таким ID уже существует — он будет
обновлен без пересоздания.

Элементы создаются из существующего TOML-конфига (.ui файла) и принадлежат классу _TomlClipInstance_. Вы можете провести дополнительные действия (задать текст,
проиграть анимацию или поставить callback на кнопку) с помощью параметров этого события.

Параметры:

| Название                         | Тип                                      | Назначение                                                   |
|----------------------------------|------------------------------------------|--------------------------------------------------------------|
| **id** <sup>(required)</sup>     | integer                                  | Уникальный ID этого элемента                                 |
| **tomlId** <sup>(required)</sup> | string                                   | TOML ID                                                      |
| **animation**                    | string                                   | Если указано: проигрывает анимацию по ее названию            |
| **x**, **y**                     | float                                    | Если указано: задает элементу его позицию на экране          |
| **texts**                        | array of { binding, text }               | Задает текст для указанных текстовых полей (по их биндингам) |
| **buttons**                      | array of { binding, client_input_value } | Задает коллбэк для указанных кнопок (по их биндингам)        |

Пример использования:

```lua
event("updateUIItem", {
    tomlId = "nt_button_blue",
    id = 10,
    x = 300.0,
    y = 300.0,
    texts = {
        { binding = "txt", text = "Click!" }
    },
    buttons = {
        { binding = "button", client_input_value = 20 }
    }
})
```

## “removeUIItem”

Обрабатывается на клиенте. Удаляет элемент интерфейса (UI) по его ID.

Параметры:

| Название                     | Тип     | Назначение                   |
|------------------------------|---------|------------------------------|
| **id** <sup>(required)</sup> | integer | Уникальный ID этого элемента |

Пример использования:

```lua
event("removeUIItem", {
    id = 10
})
```

## “scheduleTasks”

Обрабатывается на клиенте. Позволяет запланировать несколько задач за раз.

Параметры:

| Название                        | Тип   | Назначение      |
|---------------------------------|-------|-----------------|
| **tasks** <sup>(required)</sup> | array | Массив событий. |

Каждое событие в массиве **tasks** должно иметь поле **action** (string) задающее его тип. Фильтрация по таргету (поля **target_index** и **target_team**) для
внутренних событий не поддерживается.

Пример использования:

```lua
-- Spawn tutorial shelly popup and schedule its removal in 5 seconds
event("scheduleTasks", {
    tasks = {
        {
            action = "updateUIItem",
            tomlId = "nt_tutorial",
            id = 42,
            x = 300.0,
            y = 100.0,
            animation = "appear",
            texts = { { binding = "txt", "text" = "Hi there!" } }
        },
        {
            action = "removeUIItem",
            id = 42,
            delay = 5.0
        }
    },
    target_team = 0
})
```
